{# A form, not a link: logging out changes state, and a GET that changes state is fetched by anything that walks links - a browser prefetch, a link checker. CSRFProtect covers POST and not GET, so a link would also carry no token. The route still takes GET, for a browser holding HTTP Basic credentials that has to reach the 401 by typing the address. #}
