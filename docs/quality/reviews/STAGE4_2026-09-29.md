models than the one that wrote the code: **pass 3** (Sonnet) and **pass 4** (Fable). Each got
only its package (source pieces with real line numbers, SPEC.md, PLAN.txt, the task) -
`scripts/review/build_package.py`. Reports: `section_XX_pass3.json` / `section_XX_pass4.json`,
plans beside them; coverage per report with `scripts/review/coverage.py`.

delegates to a file outside its section). Section 26 pass 3 wrote bare names instead of

read-only review of the web forms covered the v3.1.0 changes there), and every section with
no change since v3.0.1.

listed here.** A finding counts once it is checked against the code, and fixed with a test
